# 🎯 TeleTabu - Telegram Tabu Oyunu Botu

Telegram grupları için geliştirilmiş, gerçek zamanlı ve çok oyunculu Tabu oyunu botu.

![Python Version](https://img.shields.io/badge/python-3.10%2B-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## 🚀 Özellikler

- **Grup İçi Oynanış:** Telegram gruplarında canlı ve etkileşimli oyun deneyimi.
- **Zamanlayıcı:** Her tur için otomatik geri sayım ve tur bitimi takibi.
- **Dinamik Arayüz:** Anlatıcıya özel çalışan Inline Butonlar (Doğru, Tabu, Pas).
- **Esnek Veritabanı:** `cards.json` üzerinden kolayca düzenlenebilir kelime kartları.
- **Anlık Skor Takibi:** Turlar arası ve oyun sonu canlı skor tablosu.
